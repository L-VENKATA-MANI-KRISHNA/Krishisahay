# KrishiSahay Datasets

To train the RAG pipeline, we need the following datasets.

## 1. Pests Data
**Target Folder:** `data/pests/`
**Source:** [Pestopia: Indian Pests and Pesticides Dataset](https://www.kaggle.com/datasets/vbookshelf/pestopia-indian-pests-and-pesticides)
**Action:** 
1. Download the dataset.
2. Extract it.
3. Ensure `pests.csv` is in `data/pests/` and images are in `data/pests/images/`.

## 2. Crops & Yield Data
**Target Folder:** `data/crops/`
**Source:** [Crop Production in India](https://www.kaggle.com/datasets/abhinand05/crop-production-in-india)
**Action:**
1. Download the CSV.
2. Place `crop_production.csv` in `data/crops/`.

## 3. Schemes (Government Data)
**Target Folder:** `data/schemes/`
**Action:**
We will use the generated `schemes.json` for now.
